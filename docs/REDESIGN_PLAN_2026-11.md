## 1. حدود الشغل (الأمان أولاً)

**هيتعدّل:** `index`, `about`, `how-it-works`, `pricing`, `join-doctor`, `contact`, `doctors`, `nearby`, `doctor.$id` (الواجهة فقط)، `specialty.*`, `articles.*`, `Header`, `Footer`, `HeroHierarchicalSearch`, `styles.css` (توكنز جديدة).

**ممنوع لمسه:** `dashboard.*` (قشرة الطبيب `.doctor-shell` وتوكنزها)، `appointments`, `profile.*`, `my-queue.*`, `consultation.*`, `notifications`, `pay`, `receipt.*`, `admin.*`, `lab.*`, `pharmacy.*`, مكونات `booking/`, `emr/`, `queue/`, `payments/`, `dashboard/`, أي hook أو `*.functions.ts` أو SQL.

**آلية الحماية:**
1. التوكنز الجديدة تتطبّق تحت كلاس `.site-public` على الصفحات العامة بس في المرحلة الأولى؛ شاشات الطبيب والمريض تفضل على توكنزها الحالية. التوحيد بعدين لو عجبك.
2. قبل أي دمج: لقطات شاشة مرجعية لـ 8 شاشات طبيب/مريض (ديسكتوب + موبايل) ومقارنة بعد كل مرحلة.
3. `tsc` + `vite build` + فحص المتصفح بعد كل مرحلة. كل مرحلة كوميت منفصل علشان الرجوع يكون بضغطة.

## 2. المراحل

### المرحلة 1 — اتجاه الهوية (قرارك قبل أي كود)
أقدّم **3 اتجاهات بصرية** كصفحة معاينة واحدة (هيرو + كارت طبيب + زر + لوحة ألوان + خط) تختار منها:
- **A — "عيادة حديثة":** تركواز عميق + نعناعي فاتح + لمسة مرجانية للأزرار. أبيض كتير، ظلال ناعمة.
- **B — "طب رقمي":** كحلي غامق + سماوي كهربائي + تدرجات زجاجية. طابع تقني واثق.
- **C — "ثقة وهدوء":** أخضر زمردي + رملي دافئ. طابع إنساني قريب من المريض.

ثوابت في كل الاتجاهات: علامة القلب + ECG تفضل، عربي أولاً بخط واحد (IBM Plex Sans Arabic) + Inter للإنجليزي، مفيش وجوه AI؛ بدلها صور حقيقية بترخيص أو رسم خطي طبي + لقطات من المنتج نفسه (شاشة الحجز، كارت الطبيب).

### المرحلة 2 — الصفحة الرئيسية
- **هيرو واحد واضح:** عنوان قصير (≤ 8 كلمات)، سطر واحد، **صندوق بحث واحد** (اسم طبيب / تخصص / عرَض) بإكمال تلقائي متسامح مع الإملاء + زرار "الأقرب لي" (GPS). **تشيل قوائم الدولة/المحافظة/المدينة/الحي.**
- أسفله: شرائح التخصصات الأكثر طلباً (8 أيقونات) بدل كروت المميزات.
- **قسم الثقة بدل الأرقام:** 3 وعود (أطباء موثّقون يدوياً، سجلّك الطبي ملكك، أسعار معلنة) — أرقام حقيقية تتعرض بس لما تعدّي حد أدنى.
- قسم الأطباء: كروت أطباء موثّقين حقيقيين (لما يكونوا موجودين) أو "كيف نوثّق الطبيب".
- **قسم للأطباء** (لأن توريد الأطباء هو عنق الزجاجة): "افتح عيادتك الرقمية" + CTA للتسجيل.
- كيف تعمل: 3 خطوات بسطر واحد لكل خطوة. الأسئلة: 4 بس، مطوية.
- شيل: فقرة الهيرو الطويلة، كروت المميزات الستة، نص "اقرأ قبل ما تحجز" المطوّل، شريط الأرقام.

### المرحلة 3 — الهيدر والفوتر وباقي الصفحات العامة
- هيدر خفيف: شعار، 4 روابط (الأطباء، للأطباء، المقالات، الأسعار)، زر "احجز الآن"، اللغة.
- فوتر: 3 أعمدة + علامة + ترخيص + روابط التطبيقات.
- `doctors`: فلاتر كشرائح أفقية (تخصص، أونلاين/عيادة، تقييم) + كارت طبيب جديد (صورة، تخصص، توثيق، سعر، أقرب موعد، زر حجز).
- `doctor.$id`: ترتيب أوضح (بطاقة تعريف لاصقة، حجز في العمود الجانبي، خريطة OSM، تقييمات).
- `pricing`, `join-doctor`, `about`, `how-it-works`, `contact`: نفس اللغة البصرية، نصوص أقصر.

### المرحلة 4 — السيو (بالأدوات المتاحة الآن)
1. **خط أساس:** `seo-audit` على mytabibi.com + `seo-page` للرئيسية و `/doctors` وصفحة تخصص — تقرير قبل/بعد.
2. **عناوين ووصف صادقة** (شيل "2,500+" نهائياً) + H1 واحد بكلمة البحث الأساسية.
3. **البيانات المنظّمة:** إضافة `MedicalOrganization` + `MedicalWebPage` للرئيسية، مراجعة `Physician`/`MedicalClinic` لصفحة الطبيب، `BreadcrumbList` في كل الصفحات العامة. فحص بـ `seo-schema`.
4. **صفحات التخصص × المدينة** (محرّك الزيارات): محتوى فريد لكل صفحة (فقرة + أسئلة + أطباء المدينة)، روابط داخلية من الرئيسية وصفحات الأطباء، sitemap محدّث بتواريخ حقيقية. فحص `seo-technical` + `seo-sitemap`.
5. **السرعة (Core Web Vitals):** خط واحد مستضاف محلياً مع preload، صور WebP/AVIF بمقاسات، تقسيم JS للصفحات العامة، lazy للخرائط والأقسام السفلية. قياس بـ `seo-performance`.
6. **GEO / محركات الذكاء الاصطناعي:** `llms.txt`، أسئلة وأجوبة قابلة للاقتباس في صفحات التخصص، إشارات العلامة. فحص `seo-geo`.
7. **السيو المحلي:** صفحات الأطباء بإحداثيات OSM + `MedicalClinic` + ساعات العمل. فحص `seo-local`.
8. **الفهرسة:** تأكيد Google Search Console + Bing (IndexNow موجود) — محتاج دخولك مرة واحدة.

### المرحلة 5 — الإغلاق
- مقارنة اللقطات المرجعية لشاشات الطبيب/المريض (لازم تطابق 100%).
- تقرير سيو بعد/قبل، نشر عبر `deploy_web.ps1`، وتحديث الذاكرة والدفتر.

## 4. قرارات مطلوبة منك قبل البدء
1. الاتجاه البصري: A أم B أم C (أو أشوف الثلاثة في صفحة معاينة الأول — موصى به).
2. الصور: صور حقيقية بترخيص (أقترح مصادر مجانية) أم رسم خطي + لقطات منتج فقط؟
3. الأرقام: تختفي تماماً لحد ما تكون حقيقية ومقنعة؟ (موصى به: نعم)
4. الرئيسية تخاطب المرضى بس، أم فيها قسم واضح لجذب الأطباء؟ (موصى به: الاثنين، المرضى أولاً)
